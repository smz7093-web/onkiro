# 테스터 모집 안내문 (10/29 작성, 발송은 PM)

카카오톡·문자에 그대로 붙여 넣는 용도. 기간은 발표일이 정해지면 바꾼다.

---

[온기로 테스트를 부탁드립니다 🙏]

안녕하세요, 빈집을 숙소로 바꾸는 서비스 '온기로'를 만들고 있는 장상민입니다.
발표 전에 실제로 써 보신 분들의 의견을 받으려고 합니다. 10~15분이면 충분합니다.

▶ 주소: https://onkiro.kr (휴대폰·PC 모두 가능)
▶ 기간: 10월 31일(토)까지

【해 보실 것】
1. 홈과 '숙소' 둘러보기 — 로그인 없이 볼 수 있어요.
2. 카카오로 로그인 → '빈집 진단 시작'
   · 아는 시골집 주소가 없으면 예시 주소 "홍성읍 오관리 595-1"을 넣어 보세요.
   · 사진은 없으면 '나중에 올리기'로 넘어가도 됩니다.
3. 공사비 견적과 수익 결과 보기
   · 견적 화면 아래 'AI 인허가 안내'에 궁금한 점을 한 줄 물어보세요.
     (예: 지하수를 쓰는데 민박 신고 때 필요한 게 있나요?)
4. 의견 남기기 — https://onkiro.kr/feedback
   · 로그인 없이 남길 수 있고, 이름·연락처는 묻지 않습니다.
   · 수익 결과 화면과 모든 화면 맨 아래에도 '의견 보내기' 링크가 있어요.

【참고】
· 금액은 참고용 추정치이며 실제 견적이 아닙니다.
· 로그아웃은 마이페이지 위쪽에 있습니다.
· 막히는 곳이 있으면 그 자체가 좋은 의견입니다. 화면 캡처와 함께 저에게 바로 알려 주셔도 됩니다.

고맙습니다!
